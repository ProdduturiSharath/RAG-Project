# Phase 7 findings

This report is generated by `scripts/phase7_eval.py`; all provider/API calls were local and cost $0.

## Authentication and API controls

- API identity is derived only from an HS256 JWT with explicit `algorithms=["HS256"]`, required `sub`, `iat`, and `exp`, and validated optional `groups`, `roles`, and `scope` claims.
- Query JSON `principal`/`groups` values are ignored; verified claims populate retrieval filters. Mutation and job routes require `admin`, `ingest`, or `ingestion` role/scope. Health is public.
- Body, query, document, section, section-count, metadata-depth/key, and retrieval parameter bounds are enforced. The process-local sliding-window limiter returns HTTP 429 with `Retry-After`; request and database timeouts are configurable.

## Prompt injection

- `extractive`: attack success 0.000 → 0.000; unverified claim survival 0.000 → 0.000; citation spoof survival 0.333 → 0.000.
- `deterministic-llm`: attack success 1.000 → 0.000; unverified claim survival 1.000 → 0.000; citation spoof survival 0.667 → 0.000.
- The adversarial set covers retrieved text, section paths, metadata, user queries, fake citation identities, and cross-version citation spoofing. Sanitized prompts redact instruction-shaped values; quote/identity/version verification rejects surviving claims and abstains.
- These are deterministic security-behavior measurements, not claims about semantic model robustness.

## PostgreSQL studies

- Study A status: **measured**.
- When available, Study A creates an isolated schema, enables and forces RLS, uses a `NOBYPASSRLS` role under `SET LOCAL ROLE`, and compares RLS-visible IDs and p50/p95 latency with explicit application ACL predicates. Any leakage is listed per principal.
- Study B status: **measured**.
- When available, Study B requires pgvector >= 0.8.7, uses selective public ACL/version filters, computes exact-scan ground truth, and compares HNSW `iterative_scan=off` and `strict_order` recall@10 and latency.
- Study A measured zero ACL leakage for all principals/groups; RLS p50/p95 values range from 0.216/0.613 ms.
- Study B used pgvector 0.8.7 and HNSW index `phase7_ann_scope_hnsw` (plan confirmed: True) over 383 selective public rows of 20756 total using {'product_version': 'pg-17', 'section_heading': 'Functions and Operators'} from source {'mode': 'phase4_snapshot_plus_phase5_artifact', 'schema': 'phase4_5d39ce69ff567132b141', 'artifact': 'phase5_outputs/vectors/baseline-bge-small.npy'}. Queries came from public vectors outside the selective filter. Both modes reached recall@10 1.000; off p50/p95 7.134/8.883 ms; strict_order p50/p95 7.024/7.700 ms.

## Limitations

- Rate limiting is process-local and should be backed by a shared store across multiple workers. JWT key rotation and asymmetric key deployment are outside this lean HS256 phase.
- RLS and ANN numbers are environment-specific and should be rerun against the production-like database after pgvector and role privileges are provisioned.
- Parent expansion, scope resolution, traces, response bodies, SSE metadata, cache invalidation, ACL mutation, and deletion are covered by local tests. The closeout suite also ran the Postgres integration and Hypothesis database paths against the configured live `evidence_rag_eval` database; the one destructive migration-reset test remains intentionally limited to a disposable database.
